# SoundLaunch

A music distribution and radio-campaign platform for independent artists and labels.

> Project overview only. The source lives in a private repository. Happy to walk through the architecture on request.

## What it does

- Manage music releases and distribute them to streaming platforms.
- Plan and run targeted radio promotion campaigns across a seeded database of radio stations.
- Run email outreach campaigns tied to those radio campaigns.
- Handle release assets through managed file storage.

## How it is built

- Next.js and TypeScript application, with Python services for data and processing work.
- Supabase for database and storage.
- Resend for transactional and campaign email.
- End-to-end tested across the release and email-campaign flows.
